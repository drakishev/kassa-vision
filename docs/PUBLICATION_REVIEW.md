# Проверка перед публикацией — 2026-10-18

Подготовлена новая история Git без импорта прежних коммитов, refs, reflog,
локальных конфигураций и служебных снимков. Исходники объединяют сайт/API
и разметчик; локальные незакоммиченные доработки сохранены в исходном коде.

## Объём проверки

Проверены 19 коммитов исследовательского репозитория и 7 коммитов релизного,
включая полученную по HTTPS публичную ветку GitHub. Дополнительно выгружены
все доступные UTF-8 Git-объекты: 1043 из исследовательского и 835 из релизного
хранилища, включая недостижимые объекты и служебные refs. Проведена отдельная
инвентаризация бинарных объектов (201 и 5 соответственно). Поиск секретов:
Gitleaks 8.30.1, проверка путей, конфигураций и ручная классификация находок.
Бинарные объекты не считались проверенными на все возможные секреты; они
целиком исключены из нового репозитория.

В прежних материалах обнаружены описания исходных записей и результаты по
отдельным видео, адреса сервера, локальные пути и данные авторов коммитов.
В служебных refs обнаружен сгенерированный API-ключ тестовой копии и базы SQLite.
Этот ключ не найден в обычной цепочке коммитов и не совпадает с проверенными
рабочими API-ключами. Срабатывания на SHA-256 и имя Python-класса разобраны
как ложные. Значения ключей и приватные записи в этот отчёт не включены.

Прежние данные, исходная Git-история и рабочие каталоги сохранены в закрытом
архиве вне проекта. Они не являются материалами для публикации.

## Новая версия

- Нет исходных видео, кадров, аннотаций, баз, ключей, старых результатов и весов.
- Вместо прежнего набора используется генератор искусственной тестовой таблицы.
- Нет адреса старого публичного сервера или путей конкретного пользователя.
- Сайт и разметчик слушают localhost; встроенный `/annotate/` требует входа.
- Новые стандартные порты: UI 18863, API 18861, разметчик 18862. Они отличаются
  от прежнего порта публичного туннеля.
- `.gitignore`, проверка точного содержимого индекса и опциональный pre-commit
  hook препятствуют повторному добавлению приватных файлов.
- Тексты лицензий сторонних компонентов и публичные нормативные источники сохранены.

## Проверки запуска

- Чистая установка CPU-профиля, `pip check`, сборка frontend.
- 101 тест backend, 88 тестов разметчика, 3 теста проверки публикации.
- 11 frontend unit-тестов и 28 проверок основного интерфейса в Chromium.
- Полная браузерная проверка разметчика отдельно и через `/annotate/`:
  воспроизведение, сохранение, конфликт версий, геометрия, AI-черновики,
  перенос эпизодов, экспорт, адаптивность и доступность.
- Проверки npm audit и pip-audit CPU-профиля: известных уязвимостей не найдено.
- Отдельный запуск сайта и разметчика из нового каталога на синтетическом видео.

GPU-инференс с весами и GPU-профиль установки заново не проверялись.
Тесты не являются оценкой качества моделей. Сканирование не даёт гарантии
обнаружения произвольных персональных данных; новые входы и результаты
нужно продолжать хранить вне Git.

## Состояние переноса

Старые процессы остановлены, относящиеся к ним user-systemd units удалены
из автозапуска и вынесены из конфигурации. Владелец отключил Tailscale Funnel;
2026-10-18 повторная проверка `tailscale funnel status --json` и
`tailscale serve status --json` вернула `{}` в обоих случаях. Маршрутов
публикации и локальных прокси в конфигурации Tailscale больше нет.

Перед переносом повторно проверен целевой репозиторий через выделенный SSH
ключ: сервер принял ключ, а `git ls-remote` не вернул ни одной ветки или тега.
Новая история публикуется в пустой репозиторий без импорта прежних коммитов.
После загрузки выполняется независимое клонирование и проверка CPU-профиля;
лишь затем удаляется временный архив прежних локальных данных.

Удаление старого репозитория не подтверждает исчезновение чужих клонов,
форков или сохранённых копий за пределами доступа владельца.
