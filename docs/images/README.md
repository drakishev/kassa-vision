# Скриншоты интерфейса

Оба PNG сняты в Chromium с текущего интерфейса на локальных синтетических
данных. Изображения не содержат кадров прежнего набора, рабочих учётных
записей, адресов сервера или результатов реального анализа.

- `site.png`: `frontend/tests/browser.mjs`, кадр `desktop-idle.png`.
  Синтетический сервер `frontend/tests/fixture.py` имитирует готовность API.
- `annotator.png`: `annotation_service/tests/run_browser.py --integrated`,
  кадр `ui-1440.png`. Видео из `make_fixture` состоит из цветных прямоугольников.

Команды запуска браузерных проверок — в [frontend/README.md](../../frontend/README.md).
Перед заменой скриншотов проверьте их визуально и обновите SHA-256 в
`scripts/check_publication.py`. Исключения разрешают только эти два файла
с проверенным содержимым; прочие изображения по-прежнему запрещены.
