# Интерфейс проверяющего

Одна деловая тема: загрузка `.mov`, отмена анализа, просмотр эпизодов и история готовых результатов. Вход выполняется по локальной учётной записи. История, видео и диагностические кадры доступны владельцу проверки.

## Запуск

Из этого каталога:

```bash
npm ci --ignore-scripts
npm run build
```

Backend из `../backend` раздаёт сборку `dist/` на порту 18863. Для разработки запустите backend и `npm run dev`: Vite проксирует `/ui/api` на `http://127.0.0.1:18863`. Сайт использует сессионную cookie; API-ключ хранится на сервере и не включается в frontend.

Разметчик встроен по `/annotate/` (общий набор для авторизованной команды).

Основной экран расположен на `/`, история — на `/history`. Старые `/v2` и `/v2/history` открывают тот же интерфейс, сохраняя параметры и фрагмент URL. Других тем и переключателей анализатора нет.

## Работа моделей

После завершения анализа кнопка «Показать работу моделей» открывает пять отдельных слоёв:

- **Исходный кадр** — сохранённое изображение без наложений.
- **Детекция** — ограничивающие рамки, уверенность и идентификаторы треков.
- **Поза** — скелет тела и точки выше выбранного порога. Для RTMW отображаются первые 17 точек тела.
- **Сегментация** — сохранённые маски только на опорном кадре, если они вычислялись.
- **Состояния** — сохранённые оценки состояний объектов, если они доступны.

Отсутствующий слой явно отмечается. Пустой результат выполненной модели отличается от отсутствующих измерений. Переключение кадров и слоёв не запускает модели повторно; порог влияет только на отображение. Сведения о модели соответствуют формату сохранённых измерений.

## Проверки

```bash
npm test
npm run build
```

Браузерные тесты работают только с синтетическими изображениями, видео и временной базой. Из корня репозитория запустите Python-окружение с зависимостями backend:

```bash
python -m uvicorn --app-dir frontend/tests fixture:app --host 127.0.0.1 --port 18765
```

Затем из `frontend`:

```bash
npx playwright install chromium
npm run test:browser
npm run test:history
```

Для диагностики запустите `npm run preview -- --host 127.0.0.1 --port 18789`, затем в другом терминале `npm run test:diagnostics`. Этот тест подменяет API и использует нарисованный SVG. Если браузер уже установлен, можно передать его путь через `CHROMIUM_PATH`.

Проверки охватывают загрузку, отмену, оба вердикта, вход и изоляцию пользователей, повторное открытие истории без нового анализа, пять диагностических слоёв, отсутствие масок вне опорного кадра, доступность и адаптивность. Артефакты записываются в `tests/results/` и не включаются в Git.

Шрифты и зависимости загружаются локально; лицензии находятся в `licenses/`. React, TypeScript, Vite, TanStack Query и Radix обеспечивают интерфейс и управление состоянием.

Для проверки разметчика в обоих режимах из корня проекта:

```bash
.venv/bin/python -m annotation_service.tests.run_browser \
  --playwright-module frontend/node_modules/playwright \
  --chromium /path/to/chromium
# Та же проверка через авторизованный маршрут основного сайта:
.venv/bin/python -m annotation_service.tests.run_browser --integrated \
  --playwright-module frontend/node_modules/playwright \
  --chromium /path/to/chromium
```

Используются временные базы и искусственные ролики. Реальные данные не читаются.
