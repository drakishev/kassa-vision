    Зоны и объекты

    0

    Зоны — полигоны на всё видео. Объекты — рамки на ключевых кадрах. Один человек сохраняет один ID.

    Перенести зоны из другого видео

    Только геометрия и классы зон. Подтвердите границы на новом видео; состояния, роли и события не копируются.

    Как быстро отметить рабочее место

    Обведите сейф, стол и стул. Выберите опорный объект и нажмите «Зона вокруг объекта». Добавьте остальные опоры, поправьте вершины и подтвердите зону. Зону клиента нарисуйте по наблюдаемому положению людей.

    Расположение сейфа — подсказка, а не подтверждение роли человека. При смене ракурса нужна отдельная зона/запись.

    Наблюдаемые интервалы

    «Человека нет» отмечайте для зоны только когда она целиком видна. «Закрыто» не означает «заперто».

    Условия для проверки

    Сопоставляем ваши интервалы. Результат — наблюдение для проверки, а не автоматическое нарушение.

    Пороги 15 / 20 / 30 с — стартовые настройки, не требования регламента.

    Что нужно разметить
    1. Создайте и подтвердите зону.
    2. Привяжите сейф / дверь / деньги к зоне в свойствах объекта.
    3. Отметьте «открыто» для сейфа или двери, «деньги есть» для денег или поверхности.
    4. Отметьте «человека нет» для этой же зоны, подтвердив полную видимость.

    «Неизвестно», «закрыто» или «человек есть» прерывают соответствующее условие. Вход и выход через дверь отмечайте событиями; право доступа из видео не определяется.

    Быстрая разметка

    1. Прочитайте ИИ-подсказку, перейдите к её таймкоду и просмотрите видео целиком.
    2. R — рамка объекта: выберите класс, протяните рамку. Для того же объекта на другом кадре нажмите «Новый ключевой кадр».
    3. Z — зона: кликните вершины, завершите Enter. Esc отменяет рисование. В режиме выбора вершины и углы можно перетаскивать.
    4. Отметьте интервал клавишами A и B, выберите состояние / событие и цель, нажмите «Добавить».
    5. Укажите имя, вывод, подтвердите полный просмотр и нажмите «Проверено».

    Пробел — пауза; ← / → — ±1 с; Shift + ← / → — по кадру; Ctrl+Z — отмена; Ctrl+S — сохранить. Горячие клавиши не перехватываются при вводе текста.

    Изменения сохраняются автоматически. Правка проверенной записи возвращает её в работу. Не размечайте невидимое: используйте «неизвестно». Для обучения детектора нужно полностью разметить нужные классы на выбранных кадрах.

    COCO: ключевые кадры проверенных видео · JSON содержит все статусы, зоны, состояния и события. COCO содержит только явно нарисованные рамки; изображения доступны по полю frame_url. Разделяйте выборки по group_id.

    Все исходники и результаты остаются на сервере. Сервис не вызывает внешние модели. Доступ рассчитан на localhost / SSH-туннель.

    Как размечать эпизоды

    1. Посмотрите ролик целиком на 1–1,5×. Для «нарушения» начните за 10 с до исходного таймкода.
    2. Добавьте участников: кассир, клиенты по порядку появления, инкассатор. Если роль не ясна — «Роль неясна».
    3. На каждом значимом действии: пауза → A в начале, B в конце → кто, действие, предмет, кому → «Добавить эпизод». Достаточно 3–8 эпизодов на ролик.
    4. Отметьте эпизод, который объясняет исходную метку, и напишите своими словами, почему.
    5. Различайте два действия. «Войти в помещение / подойти к месту клиента» — обычный визит: клиент заходит в дверь и садится напротив кассира. «Зайти на сторону кассира» — человек оказывается за рабочим столом кассира, рядом с его креслом, счётной машиной или сейфом. Расстановка мебели в роликах разная: сторону кассира определяйте по тому, где кассир работает, а не по стороне кадра.
    6. В видео без нарушения отметьте обычные действия, особенно похожие на нарушение: обычный приход клиента, обычную передачу денег, открытый сейф во время работы.
    7. Не угадывайте: если предмет не разобрать — «Не разобрать», если действие за кадром — видимость «Не видно».

    Учебный пример (вымышленный)

    На собственном учебном видео отметьте участника «Кассир 1», действие «Переместить предмет» и видимый интервал. Если действие или предмет неразличимы, выберите неопределённость. Искусственный ролик из demo содержит только тестовую таблицу и не изображает кассовые операции.

    Границы приблизительные, их нужно уточнить по видео. Метка: «Объясняет частично» — нормативный тип ещё не установлен. Роли определяет разметчик по действиям на видео. Если описание пользователя верно, модель в этом ролике перепутала, кто кому передаёт, — именно такие расхождения разметка и должна выявить.
